🛠️ Guía de Configuración Inicial (Scaffolding Guide)Este documento describe el procedimiento paso a paso para inicializar y personalizar un nuevo repositorio generado a partir de esta plantilla base.Nota: Este archivo es de uso exclusivo para el bootstrapping inicial del proyecto. El script init.sh lo eliminará automáticamente al concluir la parametrización para evitar redundancias con el README.md.📋 Requisitos PreviosGit configurado en tu máquina local.Acceso SSH validado contra GitHub (ssh -T git@github.com o el alias correspondiente como github-ues).Motor de contenedores activo (Docker Engine / Podman).🚀 Paso 1: Clonar el RepositorioClona el nuevo repositorio generado desde la plantilla e ingresa a su directorio raíz:git clone git@github-ues:<tu-usuario>/<tu-nuevo-repo>.git
cd <tu-nuevo-repo>
Asegúrate de estar posicionado sobre la rama de trabajo predeterminada (develop):git checkout develop
⚙️ Paso 2: Ejecutar el Script de InicializaciónConcede permisos de ejecución al script y lánzalo en la terminal:chmod +x init.sh
./init.sh

Verifica que el estado de cumplimiento esté en Active.Haz clic en Save changes.Esto dejará blindada la rama main contra borrados accidentales, pushes forzados (non-fast-forward) y exigirá la validación completa del pipeline de CI/CD (Lint & Validation y Build OCI Image).📤 Paso 4: Consolidar y Enviar CambiosVerifica que el árbol de trabajo esté en orden y sube la configuración base a GitHub:# 1. Comprobar archivos modificados y eliminados
git status

# 2. Agregar cambios y realizar el commit inicial
git add -A
git commit -m "chore: initialize project scaffolding and clean template setup"

# 3. Enviar a la rama develop
git push origin develop
A partir de este punto, el proyecto queda listo para el desarrollo diario del equipo bajo las instrucciones estándar de README.md.
